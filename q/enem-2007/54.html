Biologia Biologia geral

Fenômenos biológicos podem ocorrer em diferentes escalas de tempo. Assinale a opção que ordena exemplos de fenômenos biológicos, do mais lento para o mais rápido.

  1. Agerminação de uma semente, crescimento de uma árvore, fossilização de uma samambaia
  2. Bfossilização de uma samambaia, crescimento de uma árvore, germinação de uma semente
  3. Ccrescimento de uma árvore, germinação de uma semente, fossilização de uma samambaia
  4. Dfossilização de uma samambaia, germinação de uma semente, crescimento de uma árvore
  5. Egerminação de uma semente, fossilização de uma samambaia, crescimento de uma árvore

Responder e ver se acertei

Ver resposta e explicação

Resposta: B) fossilização de uma samambaia, crescimento de uma árvore, germinação de uma semente

Correção comentada

A fossilização leva milhares a milhões de anos; o crescimento de uma árvore, anos ou décadas; a germinação de uma semente, dias. Do mais lento ao mais rápido: fossilização, crescimento, germinação. Alternativa B.
