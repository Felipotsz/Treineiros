Raciocínio lógico Operações e problemas

Seja N um número natural de dois algarismos não nulos. Trocando-se a posição desses dois algarismos, obtém-se um novo número natural M de modo que N – M = 63.

A soma de todos os números naturais N que satisfazem as condições dadas é

  1. A156
  2. B164
  3. C173
  4. D187
  5. E198

Responder e ver se acertei

Ver resposta e explicação

Resposta: C) 173

Correção comentada

Se N = 10a + b e M = 10b + a, então N − M = 9(a − b) = 63, e a − b = 7. Com algarismos não nulos: N = 81 ou N = 92. Soma: 81 + 92 = 173. Alternativa C.

O 70 não vale, porque o 0 é um algarismo nulo.
