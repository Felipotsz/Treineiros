Raciocínio lógico Analogias

SIDA está para AIDS assim como 1246 está para

  1. A1462.
  2. B6421.
  3. C6241.
  4. D2461.
  5. E4612.

Responder e ver se acertei

Ver resposta e explicação

Resposta: C) 6241.

Correção comentada

Numerando as letras de SIDA (S = 1, I = 2, D = 3, A = 4), a palavra AIDS corresponde à ordem 4, 2, 3, 1. Aplicando essa ordem a 1246 (1º = 1, 2º = 2, 3º = 4, 4º = 6), temos 4º, 2º, 3º, 1º = 6, 2, 4, 1: 6241. Alternativa C.

As outras alternativas usam outras permutações dos algarismos.
