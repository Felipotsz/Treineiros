Matemática Funções

Uma caneca com água fervendo é retirada de um forno de micro-ondas. A temperatura T, em grau Celsius, da caneca, em função do tempo t, em minuto, pode ser modelada pela função \(T(t) = a + 80\, b^{t}\), representada no gráfico a seguir.

Os valores das constantes a e b são

  1. A\(a = 20;\ b = \log(0{,}5)\)
  2. B\(a = 100;\ b = 0{,}5\)
  3. C\(a = 20;\ b = (0{,}5)^{\frac{1}{10}}\)
  4. D\(a = 20;\ b = \dfrac{(40)^{\frac{1}{10}}}{80}\)
  5. E\(a = 20;\ b = 40\)

Responder e ver se acertei

Ver resposta e explicação

Resposta: C) \(a = 20;\ b = (0{,}5)^{\frac{1}{10}}\)

Correção comentada

Em t = 0, T = 100: a + 80 · b0 = a + 80 = 100, logo a = 20. No gráfico, em t = 10 a temperatura é 60 °C: 20 + 80 · b10 = 60, então b10 = 0,5 e b = (0,5)1/10. Alternativa C.

a = 100 (B) seria a temperatura inicial, não a de equilíbrio; b = 40 (E) não é uma base de decaimento (precisa estar entre 0 e 1).
