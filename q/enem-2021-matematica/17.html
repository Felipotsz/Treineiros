Matemática Equações

Para a comunicação entre dois navios é utilizado um sistema de codificação com base em valores numéricos. Para isso, são consideradas as operações triângulo Δ e estrela ∗, definidas sobre o conjunto dos números reais por \(x \Delta y = x^2 + xy - y^2\) e \(x * y = xy + x\).

O navio que deseja enviar uma mensagem deve fornecer um valor de entrada b, que irá gerar um valor de saída, a ser enviado ao navio receptor, dado pela soma das duas maiores soluções da equação \((a \Delta b) * (b \Delta a) = 0\). Cada valor possível de entrada e saída representa uma mensagem diferente já conhecida pelos dois navios.

Um navio deseja enviar ao outro a mensagem “ATENÇÃO!”. Para isso, deve utilizar o valor de entrada b = 1.

Dessa forma, o valor recebido pelo navio receptor será

  1. A\(\sqrt{5}\)
  2. B\(\sqrt{3}\)
  3. C\(\sqrt{1}\)
  4. D\(\frac{-1 + \sqrt{5}}{2}\)
  5. E\(\frac{3 + \sqrt{5}}{2}\)

Responder e ver se acertei

Ver resposta e explicação

Resposta: E) \(\frac{3 + \sqrt{5}}{2}\)

Correção comentada

Com b = 1: aΔ1 = a2 + a − 1 e 1Δa = 1 + a − a2. Como x * y = x(y + 1), a equação vira (a2 + a − 1)(2 + a − a2) = 0. Primeiro fator: a = (−1 ± √5)/2. Segundo: a2 − a − 2 = 0, a = 2 ou a = −1. As duas maiores soluções são 2 e (−1 + √5)/2, que somam (3 + √5)/2. Alternativa E.

(−1 + √5)/2 (D) é só uma das soluções.
