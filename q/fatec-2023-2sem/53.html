Vestibular FATEC, 2º semestre de 2023, questão 53

Raciocínio lógico Lógica

Em uma barraca de feira, há estas frutas: jaca, jabuticaba, morango e manga. Elas podem ser grandes ou pequenas, doces ou azedas. Sobre elas, pode constatar-se que:

• toda jaca é grande;
• algumas frutas pequenas são jabuticabas;
• alguns morangos são azedos;
• nenhuma fruta azeda é uma jabuticaba;
• toda manga é doce; e
• toda fruta grande é doce.

Com base nessas informações, assinale a alternativa correta.

  1. AAlguma fruta azeda é uma manga.
  2. BAlgum morango é pequeno.
  3. CToda fruta grande é um jaca.
  4. DAlguma jabuticaba é azeda.
  5. EToda manga é grande.

Responder e ver se acertei

Ver resposta e explicação

Resposta: B) Algum morango é pequeno.

Correção comentada

Toda fruta grande é doce, então nenhuma fruta azeda é grande: toda fruta azeda é pequena. Como alguns morangos são azedos, esses morangos são pequenos. Logo, algum morango é pequeno. Alternativa B.

Toda manga é doce, então nenhuma é azeda (A). Ser grande não obriga a ser jaca (C). Nenhuma jabuticaba é azeda (D). E nada diz que toda manga é grande (E).
