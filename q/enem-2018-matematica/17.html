Enem 2018: Matemática, questão 152

Matemática Inequações

Para criar um logotipo, um profissional da área de design gráfico deseja construí-lo utilizando o conjunto de pontos do plano na forma de um triângulo, exatamente como mostra a imagem.

Para construir tal imagem utilizando uma ferramenta gráfica, será necessário escrever algebricamente o conjunto que representa os pontos desse gráfico.

Esse conjunto é dado pelos pares ordenados (x ; y) ∈ ℕ × ℕ, tais que

  1. A0 ≤ x ≤ y ≤ 10
  2. B0 ≤ y ≤ x ≤ 10
  3. C0 ≤ x ≤ 10, 0 ≤ y ≤ 10
  4. D0 ≤ x + y ≤ 10
  5. E0 ≤ x + y ≤ 20

Responder e ver se acertei

Ver resposta e explicação

Resposta: B) 0 ≤ y ≤ x ≤ 10

Correção comentada

Os pontos estão no primeiro quadrante, com x de 0 a 10, e em cada coluna vão de y = 0 até y = x (abaixo da reta y = x). Assim, 0 ≤ y ≤ x ≤ 10. Alternativa B.

A condição 0 ≤ x ≤ y ≤ 10 (A) daria o triângulo acima da reta y = x, encostado no eixo y.
